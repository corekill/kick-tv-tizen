Soukromí bez drobných písmen.

Připojení k našemu serveru i přihlášení jsou dobrovolné. Bez souhlasu funguje anonymní sledování dál a aplikace k našemu serveru nic neposílá.

Přihlášení Kick účtu

QR kód otevře oficiální přihlášení na Kicku. Heslo zadáváš Kicku a aplikace ho nikdy nevidí. Server zpracuje OAuth autorizační kód a uchovává přístupové tokeny šifrovaně, aby mohl udržet přihlášení a načíst jméno účtu. Televize ukládá jen odvolatelnou relaci. Odhlášení smaže přihlašovací údaje této televize ze serveru.

Přihlášení nyní zobrazí jméno účtu, umožní otevřít Kick a přijímat dostupné události kanálu. Oficiální API zatím neobsahuje endpoint pro seznam Following ani zůstatek diváckých bodů. Psaní do chatu je vypnuté. Dokumentace Kick API · požadavek na endpoint Following.

Žádné online přihlášení nelze označit za bezrizikové: povolením důvěřuješ serveru Kick TV při uchování OAuth tokenů. Tok je omezený na přihlášení přes OAuth/PKCE; heslo se serveru Kick TV neposílá.

Co aplikace odešle

Po souhlasu s připojením odešle Kick TV i Kick TV Lite jeden prázdný požadavek na kicktv.corekill.cz. Každá edice má vlastní souhrnné počítadlo. Požadavek neobsahuje ID instalace, model televize, jazyk, hledání, sledované kanály ani chat.

Stejně jako u každého HTTPS spojení projde síťová adresa přes webový server a reverzní proxy. Samotný přijímač ji ale nepřebírá, neukládá ani nespojuje s výsledným počtem.

Co se uloží

  • Na serveru se pouze zvýší společné číslo instalací příslušné edice.
  • Přijímač nevytváří záznamy o jednotlivých požadavcích; jeho backendová cesta má access log vypnutý.
  • V televizi se uloží pouze příznak kicktv.installReported, aby se signál neposílal znovu.

Dobrovolná Lite diagnostika

Kick TV Lite se při prvním spuštění jasně zeptá. Dokud nezvolíš Povolit, žádná výkonová diagnostika se neposílá. Volbu lze kdykoli změnit na hlavní obrazovce.

V obou aplikacích je diagnostika součástí jediného souhlasu s připojením k serveru. Po povolení se odesílá model a firmware TV, verze Tizenu a aplikace, zatížení CPU, celková a dostupná RAM, volné úložiště, případně velikost JavaScriptové haldy, odezva event loopu a technický stav AVPlay včetně času přípravy, bufferování a chybového kódu.

Diagnostika nikdy neposílá název sledovaného kanálu, historii, chat, streamovací adresu ani stabilní identifikátor zařízení. Náhodné ID relace platí jen do dalšího spuštění aplikace. Technické záznamy se automaticky mažou po 90 dnech.

Co číslo znamená

Jde o počet prvních úspěšných spuštění od verze 2.2. Odinstalování aplikace počet nesníží. Nová instalace nebo smazání dat aplikace se může započítat znovu.

Privacy without fine print.

Server connectivity and sign-in are optional. Without consent, anonymous viewing still works and the app sends nothing to our server.

Kick account sign-in

The QR code opens Kick's official sign-in page. You enter your password with Kick; the app never sees it. The server handles the OAuth authorization code and stores access tokens encrypted so it can maintain sign-in and retrieve the account name. The TV stores only a revocable session. Signing out removes that TV's authorization from the server.

Sign-in currently shows the account name, can open Kick, and can receive available channel events. The official API has no Following list or viewer-points balance endpoint yet. Chat writing is disabled. Kick API docs · Following endpoint request.

No online sign-in is risk-free: by enabling it, you trust the Kick TV server to hold OAuth tokens. The flow is limited to OAuth/PKCE; your Kick password is not sent to the Kick TV server.

What is sent

After the user consents to server connectivity, Kick TV and Kick TV Lite each send one empty request to kicktv.corekill.cz for their separate aggregate counters. It contains no installation ID, TV model, language, searches, watched channels, or chat.

As with every HTTPS connection, the network address passes through the web server and reverse proxy. The counter receiver itself does not accept, store, or associate it with the resulting total.

What is stored

  • The server only increments the shared aggregate total for the corresponding edition.
  • The receiver creates no per-request records, and its backend routes have access logging disabled.
  • The TV stores only a local flag so the first-launch signal is not sent again.

Optional diagnostics

In both apps, technical diagnostics are part of the single server-consent setting. The app asks explicitly before sending anything to our service.

When enabled, the app sends the TV model and firmware, Tizen and app versions, CPU load, total and available memory, free storage, optional JavaScript heap size, event-loop responsiveness, and technical AVPlay timing, buffering, state, and error information.

It never sends the watched channel, history, chat, stream URLs, or a stable device identifier. A random session ID lasts only until the app is restarted. Technical records are deleted automatically after 90 days.

What the number means

It is the number of first successful launches since version 2.2. Uninstalling the app does not decrease it. A reinstall or clearing the app data may be counted again.
